# Hasta-Shilpa

Hasta-Shilpa is a GenAI-inspired Android application designed to help bamboo and cane artisans modernize traditional crafts through design inspiration, blueprint viewing, material tracking, and intelligent price suggestion tools.

## Features

- Trending bamboo product ideas
- Blueprint viewing
- Material tracking
- Price suggestion calculator
- Marketplace prototype

## Technologies Used

- Android Studio
- Kotlin
- Jetpack Compose
- MVVM Architecture

## Problem Statement

Traditional bamboo and cane artisans often continue producing repetitive designs that no longer appeal to modern urban markets. Hasta-Shilpa bridges traditional craftsmanship with modern design trends using digital tools and AI-inspired solutions.

## Vision

The app aims to support artisans by improving product value, promoting sustainable bamboo products, and increasing access to modern markets.
